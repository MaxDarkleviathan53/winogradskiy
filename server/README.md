# Инструкция по развертыванию бэкенда на сервере 94.247.230.221

Этот каталог содержит исходный код сервера авторизации и синхронизации баланса для приложения Winogradsky Institute. Сервер написан на Node.js с использованием Express и SQLite в качестве базы данных.

---

## 1. Подготовка файлов на сервере

Скопируйте содержимое папки `server/` на ваш сервер `94.247.230.221` (например, в директорию `/var/www/winogradsky-backend` или любую другую по вашему выбору).

Каталог должен содержать следующие файлы:
- `package.json` — конфигурация зависимостей.
- `server.js` — код бэкенд-сервера.
- `README.md` — эта инструкция.

---

## 2. Установка зависимостей

Подключитесь к вашему серверу по SSH, перейдите в созданную папку бэкенда и выполните команду для установки пакетов:

```bash
cd /путь/к/папке/winogradsky-backend
npm install
```

Эта команда установит необходимые библиотеки:
- `express` — веб-фреймворк.
- `cors` — обработка CORS-запросов от WebView.
- `sqlite3` — драйвер базы данных SQLite (база данных `database.sqlite` создается автоматически в этой же папке при первом запуске).
- `bcryptjs` — шифрование паролей пользователей.
- `jsonwebtoken` — создание и валидация токенов сессий (JWT).

---

## 3. Запуск сервера

Для тестирования вы можете запустить сервер напрямую:

```bash
npm start
```
Вы должны увидеть сообщение:
`Winogradsky Backend is running on port 5000`

### Постоянная работа в фоне (Рекомендуется)
Чтобы сервер продолжал работу после закрытия терминала SSH, рекомендуется использовать менеджер процессов **PM2**:

1. Установите PM2 глобально (если он еще не установлен):
   ```bash
   npm install -g pm2
   ```

2. Запустите сервер под управлением PM2:
   ```bash
   pm2 start server.js --name "winogradsky-backend"
   ```

3. Чтобы сервер автоматически запускался при перезагрузке ОС:
   ```bash
   pm2 startup
   pm2 save
   ```

4. Полезные команды PM2:
   - `pm2 status` — проверить состояние сервера.
   - `pm2 logs` — просмотр логов в реальном времени.
   - `pm2 restart winogradsky-backend` — перезапустить сервер.

---

## 4. Настройка брандмауэра (Firewall)

Убедитесь, что на вашем сервере открыт порт **5000** для входящих запросов, так как мобильное приложение WebView будет отправлять запросы по адресу `http://94.247.230.221:5000`.

Если на сервере используется `ufw` (стандартный брандмауэр в Ubuntu), выполните команду:
```bash
sudo ufw allow 5000/tcp
```
Или откройте порт 5000 в панели управления вашим хостинг-провайдером.
